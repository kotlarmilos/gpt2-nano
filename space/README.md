# gpt2-nano KV-cache

This Space compares cached and uncached greedy decoding with the published
gpt2-nano checkpoint. It downloads the signed-off checkpoint and tokenizer from
`kotlarmilos/gpt2-nano`. The local wheel beside `app.py` contains the exact
runtime implementation under review.
